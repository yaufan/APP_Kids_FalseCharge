# 眼尖尖大挑戰的聲音

所有聲音都是用程式合成的（numpy、scipy）：沒有錄音、沒有下載別人的素材，三首曲子都是為這個 APP 新寫的。

- 合成用的小工具（鐘聲、木琴、撥弦、玩具小喇叭、彈簧聲、接成循環、量音量、人聲的共鳴方法……）是從想一想樂園的 `design/sounds/make_sounds.py` 複製過來的（它們大多又是從小卡認天下、動物小餐廳、字母寵物來的）。
- 新做的有：單簧管（豎笛）、顫音琴（vibraphone）、溫暖的長音（pad）、一點小房間的回聲（讓東西聽起來遠遠的）、遠遠的人聲（夜市）、小鳥的叫聲，三首曲子，以及其他的聲音。

給 2～5 歲的小朋友，所以**好玩、溫暖、柔和**：沒有刺耳或突然的聲音；點錯了只是很輕的「噗」，不是答錯的警告聲，也不會聽起來難過。

做的時候沒辦法用耳朵聽，是看數字（長度、音量、破音、接頭）和頻譜圖（聲音裡每個高低的音在什麼時候出現）檢查的；請在手機上聽聽看，覺得哪個不好聽再改。

## 怎麼產生

```
pip install numpy scipy                                     # 只要第一次
python3 design/sounds/make_sounds.py                        # 寫到 app/assets/sounds/*.wav
python3 design/sounds/make_sounds.py preview 試聽.m4a        # 再做一個試聽檔（要 ffmpeg）
```

跑完會印出每個檔案的長度、大小、最大音量、聽起來多大聲、有沒有破音、頭尾的點，還有背景音樂接頭的檢查，和旋律比伴奏響多少。
- 亂數都用固定的種子，每次跑出來的檔案都一模一樣（一個 byte 都不差）。
- 程式會檢查：檔名剛好是下面這些、音效和場景的聲音不超過 1.5 秒、背景音樂 16～20 秒、音效頭尾都是 0。
- 全部加起來超過 3,500,000 bytes 就會停下來報錯。
- 試聽檔是每首背景音樂的前 8 秒，接著每個音效和場景的聲音照順序播一次，中間停一下，會印出每一段從第幾秒開始。

## 格式
- 全部是 WAV、單聲道、16 位元。
- 背景音樂 16,000 Hz；其他聲音 22,050 Hz。
- 背景音樂都是整數小節，可以無縫循環：曲子結尾還在響的聲音接回開頭，聽不出接縫。程式用兩個方法檢查接頭：最後一個點跳回第一個點的差距（要比接頭前後 0.02 秒裡最大的一步小），和接頭前後 0.02 秒的高音（如果有「啪」一聲會在這裡冒出來；要比曲子其他地方最響的一段小很多）。
- 其他聲音兩頭都有淡入淡出，第一個和最後一個點都是 0，不會「啪」一聲。
- **音量一樣大**：程式量每個聲音「從手機喇叭聽起來」有多大聲。
  - 怎麼量：用耳朵比較敏感的頻率（A 加權）、不算手機放不出來的低音，大約 0.2 秒一段（耳朵大約這樣把聲音加起來）。
  - 再把每個聲音調到一樣大聲（約 −21 dB）：該輕一點的就小幾 dB。例如按鈕、點錯、畫圈、下一張，都放得比較輕（點錯最輕，−27 dB）。
  - 最大音量不超過 0.72。印章是很短的一下，把最尖的地方磨圓一點（輕輕的飽和），才能和別的一樣大聲。
  - 和兄弟 APP 的音效差不多大聲。
- 場景的聲音（`amb_…`）是**打開場景時播一次**的短聲音，不是一直循環的背景聲；比音效輕約 3～4 dB（約 −24～−25 dB）。
- 背景音樂聽起來比音效輕約 8 dB（首頁 −29 dB；找不同的時候 −30.5 dB，比首頁再輕一點，不吵；休息的搖籃曲 −30 dB），放在念名字和音效下面。
- 每首曲子的旋律比伴奏響約 11～12 dB（從手機聽），旋律清楚，伴奏也聽得到。
- 手機小喇叭放不出很低的聲音。所以印章的「咚」、「喔噗！」、號角曲的低音、海浪這些低低的，都加了一點它自己比較高的泛音（也就是聲音裡比較高的那些成分），手機上才聽得到。
- 全部 23 個檔，加起來約 2.5 MB（2,515,652 bytes），在 3.5 MB 以內。

## 背景音樂

三首的拍子、調、樂器都不一樣，小朋友一聽就知道自己在哪裡；也和兄弟 APP 的曲子都不一樣（兄弟 APP 用過的：C、D、E、F、G、A、降 B、降 E 大調，搖籃曲都是三拍或六拍）。

| 檔案 | 用在哪裡 | 長度 | 聽起來 |
|---|---|---|---|
| `music_home` | 首頁 | 18.0 秒 | 好奇、調皮、躡手躡腳：四拍子、A 小調，後半首轉到 C 大調變亮。軟軟的單簧管吹旋律，短短輕輕的音，中間常常停一下，第一小節有一個偷偷溜過去的半音；撥弦（pizzicato）在下面踮著腳走：低音在一、三拍，短短的和弦在二、四拍，每個反拍有一聲小小的木頭「滴」。後半首旋律往上走，鐵琴叮叮跟著，加進輕輕的鼓和沙鈴；最後低音「Mi－Re－Do－Si」踮著腳走回開頭 |
| `music_play` | 找不同的時候 | 17.6 秒 | 安靜、專心、開心，不搶注意力：四拍子、降 A 大調，用柔和的七和弦。顫音琴（琴管上有轉動的小風扇，聲音會輕輕「哇哇」晃）慢慢唱長長的音，後半首多一個顫音琴在下面和聲；馬林巴琴用八分音符輕輕上下滾著和弦，低音撥弦每小節一下，沙鈴很輕地打拍子；每半首結尾馬林巴「叮叮叮」小小回答一下。比首頁的曲子輕一點 |
| `music_rest` | 休息時間 | 19.2 秒 | 很慢的搖籃曲：降 D 大調，慢慢的四拍子（和兄弟 APP 一搖一搖的三拍、六拍搖籃曲不一樣）。鋼片琴（celesta）唱旋律，下面是溫暖、慢慢呼吸的長音，低音像心跳一樣在一、三拍輕輕「咚」；前半首結尾音樂盒回答三個音，後半首音樂盒高八度跟著唱，最後三聲輕輕的鐘聲 |

## 場景打開時的聲音

打開場景時播一次，告訴小朋友「我們到了哪裡」。

| 檔案 | 場景 | 長度 | 聽起來 |
|---|---|---|---|
| `amb_park` | 公園 | 1.38 秒 | 一陣微風吹過樹葉；一隻白頭翁唱四個音的小句子，另一隻小鳥用很快的高音顫音回答 |
| `amb_market` | 夜市 | 1.44 秒 | 很多人在遠遠的地方輕輕聊天（聽不出字），攤子上的小手搖鈴「叮、叮」 |
| `amb_beach` | 海邊 | 1.42 秒 | 一個溫柔的浪打上來再退回去（浪聲慢慢變大，接著泡沫沙沙），遠遠的海鷗「啾～喔」叫兩聲 |
| `amb_zoo` | 動物園 | 1.44 秒 | 遠遠的大象友善地「嘟～」一聲（往上、搖一搖，因為遠所以柔柔的）；前面小鳥「嗶嗶」，後面熱帶鳥「咻－嗚」 |
| `amb_party` | 生日派對 | 1.31 秒 | 派對吹笛「嗶～」展開（有紙捲開的沙沙聲），接著小小的歡呼：三個小小的「耶！」和一串往上的鈴聲 |
| `amb_kitchen` | 廚房 | 1.38 秒 | 鍋子裡輕輕滋滋地煎著（細細的嘶嘶聲和小小的劈啪），鍋蓋放下「鏘、鏘」再輕輕晃一下 |

小變和人的聲音和兄弟 APP 一樣，是這樣做的：
- 用一個嗡嗡聲（像聲帶），通過幾個共鳴（像嘴巴的形狀），做出「嘻嘻」「喔噗」「哈～啊」「耶」這些聲音；嘴巴的形狀可以慢慢變，例如「嗚」變「喔」。
- 夜市的人聲是七個遠遠的聲音，每個隨便說一些母音（沒有字），疊在一起再加一點回聲。
- 小鳥是單純的口哨音，高低跟著叫聲的樣子走；海鷗和大象是有很多泛音的聲音，通過共鳴再變柔。
- 風、海浪、煎東西、翻紙、筆、咻，用沙沙的雜音通過會移動的共鳴合成。
