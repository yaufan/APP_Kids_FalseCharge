# 設計提案：咦！哪裡不一樣？（找碴遊戲，名稱暫定）

> 給 2～5 歲小朋友的找碴遊戲。2026-11-06 提案，最後面「要決定的事」等家長選。草圖在 `docs/mockups/`。和「畫畫小鎮」「字母寵物」「動物小餐廳」「小卡認天下」「想一想樂園」是同一個作者的兄弟 APP，同一套技術，畫風不同。

## 給誰
- **2～5 歲**，在台灣，國語為主。分三個難度：

| 難度 | 年齡 | 大概的樣子 |
|---|---|---|
| 小小 | 2～3 歲 | 一次只看一張圖、一個不一樣，而且很大很明顯（顏色、不見了） |
| 中 | 3～4 歲 | 兩張圖找 3 個不一樣，都是看得清楚的大東西 |
| 大 | 4～5 歲 | 兩張圖找 5 個不一樣，有方向、數量、花紋這些比較細的 |

- 一般的「兩張圖找不同」對 2 歲太難：要同時記住兩張圖、來回比。所以 2 歲先從「哪一個不一樣」「哪裡變了」開始，慢慢才到兩張圖。
- 不連網、不定位、沒有廣告、沒有帳號（和兄弟 APP 一樣）。

## 練什麼
- **仔細看**（視覺辨別）：顏色、形狀、大小、方向、數量的不同。
- **專心和記憶**：記住剛才的樣子，找出哪裡變了。
- **說出來**：找到時說「氣球變藍色了！」「小狗不見了！」，學顏色、方位、數量的說法。
- 點一下圖裡的東西會念出名字（家長可以加英文），順便認識東西。

## 主角：變色龍「小變」
- 綠色的小變色龍，眼睛圓圓、尾巴捲捲，很調皮：最喜歡偷偷**把圖裡的東西變一下**，還會**變色躲起來**。小朋友的任務是抓出小變做了什麼、找到小變躲在哪。
- 找到了小變會不好意思地笑，變回原來的樣子。

## 四種玩法（0.1 建議）

### 1. 哪一個不一樣？（小小起）
- 三、四個一樣的東西排一排（小鴨子），其中一個不一樣：戴帽子、顏色不同、方向相反。點那一個。
- 最簡單的「找碴」：一眼就能比，2 歲也做得到。

### 2. 小變變了什麼？（小小起）
- 一張圖，小變「變！」一聲，圖裡有一個東西變了：顏色換了、不見了、多了一個。點變了的地方。
- 小小：變的是大東西，變的時候會閃一下；中、大：一次變兩個、不閃、要自己記。

### 3. 兩張找不同（中、大）
- 手機直著拿，兩張圖上下排。點任何一張都可以，找到的地方兩張都會圈起來。
- 中 3 個、大 5 個；上面有小圓點數著還剩幾個。
- 沒有倒數、沒有扣分。點錯只有輕輕的「噗」，不會怎樣。

### 4. 小變躲在哪裡？（小小起）
- 熱鬧的場景裡，小變變色躲起來，只露出眼睛和捲尾巴。找到牠。
- 小小：露很多；大：躲得很好，要仔細看。

### 以後的玩法（0.2 起）
- **記住再找**：先看 5 秒，圖蓋起來再打開，找出哪裡變了。
- **影子配對**、**找出一樣的兩個**（配對）。
- **自己出題**：家長模式拍一張家裡的照片，APP 自動變一個地方，讓小朋友找（不上傳，只存在手機）。

## 場景（0.1 建議 6 個，台灣的日常）
公園（溜滑梯、鞦韆、鴨子池）、夜市（攤販、燈籠、氣球）、海邊（沙堡、螃蟹、救生圈）、動物園、生日派對（蛋糕、蠟燭、禮物）、廚房。以後：臥室、菜市場、公車站、下雨天、農場、水族館。

## 不一樣的種類（由簡單到難）
1. **顏色換了**（紅氣球 → 藍氣球）
2. **不見了／多了一個**
3. **大小變了**
4. **方向反了**（小鴨子往左 → 往右）
5. **數量變了**（三顆蘋果 → 兩顆）
6. **換成別的**（貓 → 狗）
7. **花紋、表情變了**（條紋 → 點點、笑臉 → 驚訝）

小小只用 1、2，而且只用大東西；中用 1～4；大全部都用。

## 題目是程式做出來的
- 每個場景是一個背景加上十幾樣東西，每樣東西是單獨的圖，還有它的變化（換顏色、反過來、別的東西）。
- 每一題由程式從場景裡挑幾樣東西來變，所以同一個場景可以玩很多次都不一樣。
- 測試會檢查：每個不一樣的地方夠大、不會跟別的重疊、小小的題目只用大東西。

## 不會失敗
- 沒有倒數、沒有扣分、點錯不會怎樣。
- **提示**：點放大鏡，小變會在一個還沒找到的地方附近閃一下；小小玩 20 秒沒找到，會自動提示。
- 找到時念出來：「氣球變藍色了！」

## 獎勵
- 一個場景玩完，場景卡變成彩色、蓋上小變的印章，放進「相簿」；每個場景最多 3 顆星。

## 每次玩多久
- 家長設定，**預設 10 分鐘**（2 歲小朋友眼睛要多休息），可以改。時間到了小變打哈欠、場景天黑，要家長解開或等一個小時才能再玩（和兄弟 APP 一樣）。

## 家長模式（要過家長關卡）
- 年齡（難度）、每次玩多久、提示多或少、聲音、念名字、英文。
- 看玩過哪些場景、找到幾個。
- 以後的完整版購買只在這裡。

## 畫風（三種給家長選）
要和兄弟 APP 都不一樣，而且找碴需要**東西清楚、一個一個分得開**。
- **A 等角小模型風**（建議）：像從斜上方看一個小小的玩具世界，平平的光影、圓角、沒有外框，東西多又清楚，很適合找碴。
- **B 孔版印刷風**：像三、四色油墨印出來的版畫，顏色疊在一起會變新顏色，有一點點錯位和顆粒，很有設計感。
- **C 粗蠟筆童畫風**：像小朋友用粗蠟筆畫的，線條歪歪的、蠟筆紋路，親切。

## 以後上架和收費（和兄弟 APP 一樣）
- 免費下載：公園和海邊兩個場景。
- 一次買斷完整版：全部場景和玩法。購買只在家長模式。

## 版本計畫（建議）
- **0.1**：四種玩法、三個難度、6 個場景、小變、相簿、休息時間、家長模式、音樂和音效、APP 圖示。
- **0.2**：記住再找、影子配對、更多場景。
- **0.3**：家長拍照自己出題、英文。

## 技術（和兄弟 APP 一樣）
- Flutter（Android 和 iOS）、Riverpod、flutter_svg、audioplayers、flutter_tts；存檔是一個 JSON 檔。
- 點的地方用原始的手指事件（`Listener`），手指一碰就算。
- 圖用 Python 畫 SVG，聲音用 numpy 合成，不用別人的素材。
- 資安和兄弟 APP 一樣：不接受別的 APP 傳來的頁面、家長模式只能從家長關卡進去、不要任何權限。
